# Case Workspace

Рабочее пространство для ведения уголовных дел и формирования документов.

## Установка

    pip install -e .[dev]

## Запуск

    case-workspace

или

    python -m case_workspace

## Тесты

    pytest

## Что реализовано (этап 1)

- Регистрация первого администратора (ФИО, орган, пароль по политике)
- Вход по паролю (argon2)
- Блокировка после 5 неудачных попыток: 1 → 5 → 15 → 45 → 120 мин
- Роли Admin / User
- SQLite-БД, логи

## Что дальше (этапы 2+)

Дела, участники, идентификаторы, документы, бланки, тайминг, бэкап, OCR, бот.
